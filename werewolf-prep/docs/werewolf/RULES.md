## 1. ภาพรวม

ผู้เล่นทุกคนได้ **บทบาทลับ** แล้วเกมวนเป็นรอบ: **กลางคืน → เช้า → กลางวัน (พูดคุย → เสนอชื่อ → แก้ตัว → โหวต) → กำจัด → ตรวจผู้ชนะ → กลางคืนถัดไป** จนมีฝ่ายหรือบทใดบทหนึ่งชนะ

ผู้ดำเนินเกม = **เซิร์ฟเวอร์** (ไม่มีฝ่าย ไม่ช่วยใคร ไม่ใบ้ ไม่เปิดบทโดยไม่ได้รับอนุญาต ไม่เปลี่ยนผลโดยไม่มีเหตุผลตามกฎ)
ผู้เล่นโกหกเรื่องบทได้ทุกฝ่าย · รองรับ **5–30 คน** (กลุ่มเป้าหมายหลัก 15 คนขึ้นไป — Q2)

## 2. โมเดลฝ่าย

ข้อมูลของทุกผู้เล่นแยกเป็น 2 ชั้น (ตาม `SPECIAL_ROLES.md`):

| ฟิลด์ | ความหมาย |
|---|---|
| `roleId` | บทของผู้เล่น — **ชื่อบทไม่เปลี่ยนแม้เปลี่ยนฝ่าย** (ยกเว้นบทที่ระบุว่า "กลายเป็นบทหมาป่า") |
| `kind` | ประเภท: `normal` · `special` · `neutral` |
| `startTeam` / `team` | ฝ่ายตอนเริ่ม / ฝ่ายปัจจุบัน: `village` `wolf` `vampire` `cult` `solo` |
| `winWith` | ชนะพร้อมใคร: `village` `wolf` `vampire` `cult` `self` (เงื่อนไขเฉพาะ) `follow` (ตามบทที่ลอก/ตามสถานะ) |
| `lover` | อยู่ในคู่รักหรือไม่ (ซ้อนทับฝ่ายอื่น ไม่ทับกัน) |

เมื่อเปลี่ยนฝ่าย ต้องอัปเดต `team` + `winWith` + สิทธิ์รู้จักใคร + ความสามารถ
ฝ่ายหลักตามต้นฉบับมี 3 กลุ่ม (หมู่บ้าน / หมาป่า / อิสระ) แต่ **แวมไพร์** และ **ลัทธิ** เป็นทีมอิสระที่ชนะเป็นทีมของตัวเอง

## 3. พรีเซ็ตและชุดบท

| ผู้เล่น | ชุดบท |
|---|---|
| **8** | ชาวบ้าน 4 · ผู้หยั่งรู้ · หมอ · หมาป่า 2 |
| **10** | ชาวบ้าน 4 · ผู้หยั่งรู้ · หมอ · นายพราน · หมาป่า 2 · คนฟอก |
| **15** | ชาวบ้าน 4 · ผู้หยั่งรู้ · หมอ · แม่มด · นายพราน · ช่างก่อสร้าง · หมาป่า 3 · ลูกหมาป่า · ผู้พยากรณ์ของหมาป่า · คนฟอก |
| **20** | ชาวบ้าน 4 (ต้นฉบับ 5 → ลด 1 ให้ครบ 20) · ผู้หยั่งรู้ · หมอ · แม่มด · นายพราน · ช่างก่อสร้าง 2 · หมาป่า 4 · หมาป่าอัลฟ่า · ลูกหมาป่า · ผู้พยากรณ์ของหมาป่า · สมุนหมาป่า · คนฟอก · ฆาตกรเดี่ยว |

> ⚠ **ข้อสังเกตจากการนับ:** ชุด "20 คน" ในต้นฉบับรวมได้ **21 คน** (เกิน 1) → ปุ่ม "ค่ามาตรฐาน" ใช้ **ชาวบ้าน 4** แทน 5 ให้พอดี 20 (ดู Q24) · ชุด 20/25 มีฝ่ายหมาป่ารวม 8 คน (40%) เกิน ¼ ที่ตัวช่วยสมดุลแนะนำ แต่ยังน้อยกว่าครึ่ง → ตัวช่วย **เตือนแต่ไม่ห้าม**
> พรีเซ็ตเสริม: **มือใหม่** (ชาวบ้าน · หมาป่า · ผู้หยั่งรู้ · หมอ) · **กำหนดเอง** (ติ๊กบททีละตัว)

**ตรวจก่อนเริ่ม (ห้ามเริ่มถ้าไม่ผ่าน):** จำนวนบท = จำนวนผู้เล่น · ช่างก่อสร้างต้อง ≥ 2 · มีบทที่ "ฆ่าได้ฝั่งหมาป่า" ≥ 1 · ฝ่ายหมาป่ารวมต้องน้อยกว่าครึ่ง · ทุกบทต้องมีเงื่อนไขชนะ (SPECIAL_ROLES ข้อ 7)

## 4. เฟสของเกม

```
LOBBY → ROLE_REVEAL → [ NIGHT → DAWN_RESOLVE → MORNING → DISCUSSION → NOMINATION → DEFENSE → VOTE → EXECUTION ] วนซ้ำ → GAME_OVER
```

| เฟส | สิ่งที่เกิด |
|---|---|
| LOBBY | เข้าห้อง ตั้งค่า เลือกชุดบท ตรวจจำนวน |
| ROLE_REVEAL | แจกบทลับ ทุกคนกด "พร้อม" |
| NIGHT | เรียกบทตามช่อง (ข้อ 5) ทุกช่องกินเวลาสุ่มช่วงเดียวกัน กันเดาจากเวลา |
| DAWN_RESOLVE | เซิร์ฟเวอร์ประมวลผลท่อ 10 ขั้น (ข้อ 6) ไม่มี UI |
| MORNING | ประกาศผู้ตาย + ส่ง "ผลลับ" ของแต่ละคนเป็นข้อความส่วนตัว **พร้อมกัน** · ตรวจผู้ชนะ |
| DISCUSSION | พูดคุย มีตัวจับเวลา · โหมดคุย: แชท / เสียงภายนอก / ทั้งคู่ (Q5 เจ้าของห้องเลือก) · มือปืนยิงได้ช่วงนี้ |
| NOMINATION | ผู้รอดแต่ละคนเสนอชื่อได้ 1 คน 🔸A1 |
| DEFENSE | ผู้ถูกเสนอชื่อแก้ตัวคนละ 30 วินาที (ตั้งค่าได้) |
| VOTE | โหวต (ข้อ 7) |
| EXECUTION | ประกาศผล + ผลพลอยได้ (ตัวตลก เจ้าชาย คนโง่ นายพราน) · ตรวจผู้ชนะ |

- **★ ตรวจผู้ชนะทุกครั้งที่มีผู้ตายหรือเปลี่ยนฝ่าย** ไม่ใช่เฉพาะท้ายรอบ
- **คืนแรก:** หมาป่าฆ่าได้ไหม — ค่าเริ่มต้น **ได้** (ตั้งค่าได้)
- **เมื่อมีผู้ตาย:** **เปิดบทเฉพาะผู้ที่ถูกโหวตตาย (และลูกโซ่หลังโหวต) — ตายกลางคืนไม่เปิดบท** (ค่าเริ่มต้น ตามผู้ใช้สั่ง 2026-10-02) / เปิดบทเต็มทุกกรณี / เปิดแค่ฝ่าย / เปิดแค่ว่าเป็นหมาป่าหรือไม่ / ไม่เปิด

## 5. ลำดับตื่นกลางคืน

ข้ามบทที่ไม่มี/ตายแล้ว **ด้วยการหน่วงเวลาเท่ากันเสมอ** (GAME_SPEC ข้อ 4.1) ลำดับเรียงตามเหตุผล 3 ข้อ: ① ผู้ขัดขวางมาก่อนผู้ถูกขัด ② แม่มดมาหลังฝูงหมาป่า (ต้องเห็นเหยื่อ) ③ **ผลสืบสวนทุกชนิดประมวลผลตอนจบคืน** เพื่อให้ผู้สลับชะตา/กระจกทำงานได้และไม่มีใครเดาจากจังหวะ

## 6. ท่อประมวลผลกลางคืน (สำคัญที่สุด)

**หลักการ (ข้อ 15 ต้นฉบับ):** คำสั่งฆ่า **ไม่ทำให้ใครตายทันที** ทุกการกระทำถูกเก็บเป็น "เจตนา" (intent) ในลิสต์ แล้วเซิร์ฟเวอร์ประมวลผลตามขั้น **เป๊ะๆ** ทุกขั้นเขียนลง `ww_events_private`

```
ขั้น 1  ขัดขวาง (Blocks)
        ผู้หยุดความสามารถ / หมาป่าผู้หยุด / หญิงชรา(ฝั่งกลางคืน) → เจตนาของคนที่ถูกขัดถูกยกเลิก
        (ไม่ตัดจำนวนครั้งที่ใช้ได้ · ผู้ถูกขัดได้รับแจ้ง "ความสามารถถูกขัดขวาง" ตั้งค่าได้)

ขั้น 2  สลับชะตา (Swap)
        ผู้สลับชะตาสลับ A↔B ใน "ทุกเจตนาที่มีเป้าหมาย" ของคนอื่น (ฆ่า กัน ชุบ สืบสวน…) แบบสมมาตร
        เช่น หมาป่าเลือก A + หมอกัน B → กลายเป็น หมาป่าเลือก B + หมอกัน A

ขั้น 3  สะท้อน (Mirror)
        เจตนา "โจมตี/สืบสวน" ที่เป้าหมายเป็นกระจก → ย้อนกลับไปที่ผู้ใช้ 🔸A6

ขั้น 4  ป้องกัน (Protect)
        หมอ / นักบวช / ผู้คุ้มกัน กันตามตารางข้อ 11.2
        ผู้คุ้มกัน: ผู้ถูกโจมตีรอด แต่ผู้คุ้มกันตายแทน

ขั้น 5  ภูมิคุ้มกัน/ผลพิเศษของเป้าหมาย
        ชาวบ้านต้องคำสาป (ถูกกัดไม่ตาย แต่จะเปลี่ยนฝ่าย) · คนถึก (ตายตอนจบคืนถัดไป) · ผู้ถูกแพร่เชื้อ

ขั้น 6  ยาแม่มด
        ชุบ → ลบคนนั้นออกจากรายชื่อตาย (ถ้าหมอ/นักบวชกันไว้แล้ว → แม่มดได้ยาคืน ตั้งค่าได้)
        พิษ → เพิ่มเข้ารายชื่อตาย (หมอ/ผู้คุ้มกันกันไม่ได้ · นักบวชก็ทะลุ)

ขั้น 7  ยืนยันรายชื่อตาย
        ตายครั้งเดียวไม่นับซ้ำ → เขียน event

ขั้น 8  ลูกโซ่หลังตาย (วนจนไม่มีใครตายเพิ่ม ลิมิต 50 รอบ)
        คู่รักตายตาม → นายพรานยิง → ผู้ถูกแพร่เชื้อ/คนถึก/ผู้พิทักษ์ที่ถึงเวลา
        → เด็กป่า/มนุษย์ป่าแปลงเมื่อต้นแบบตาย → ศิษย์ผู้หยั่งรู้เลื่อนขั้น → ลูกหมาป่าตาย (คืนถัดไปฆ่า 2)

ขั้น 9  เปลี่ยนฝ่าย
        ประมวลผลการเปลี่ยนฝ่ายทั้งหมด (อัลฟ่า/คำสาป/เด็กป่า/มนุษย์ป่า/ลัทธิ/แวมไพร์/แพร่เชื้อ) · อัปเดต team, winWith

ขั้น 10 ผลสืบสวน + ตรวจผู้ชนะ
        คำนวณผลของผู้ตรวจทุกประเภท (ตามสถานะ "ก่อนขั้น 8–9" ของคืนนั้น) ส่งเป็นข้อความส่วนตัวตอนเช้า
        แล้วตรวจผู้ชนะ (ข้อ 8)
```

**เคสที่ต้องมีเทสต์ครบ:**

| สถานการณ์ | ผลที่ถูก |
|---|---|
| หมาป่ากัด A + หมอกัน A | A รอด |
| หมาป่ากัด A + หมอกัน A + แม่มดชุบ A | A รอด · แม่มดได้ยาชุบคืน (ค่าเริ่มต้น) |
| หมาป่ากัด A + แม่มดวางยา A | A ตาย (ตายครั้งเดียว) |
| หมอกัน A + แม่มดวางยา A | A ตาย (หมอไม่กันพิษ) |

## 7. กลางวัน เสนอชื่อ โหวต

- **พูดคุย:** ผู้รอดพูด กล่าวหา แก้ตัว อ้างบท โกหกได้ · ผู้ตายห้ามพูด/ใบ้/โหวต (ข้อ 9)
- **เสนอชื่อ 🔸A1:** ผู้รอดแต่ละคนเสนอชื่อ 1 คน (เสนอตัวเองไม่ได้) · ผู้ที่ถูกเสนอมากสุด **3 คน** (เท่ากันเรียงตามเวลา) เป็นผู้ถูกเสนอชื่อ · ไม่มีใครถูกเสนอ = ข้ามโหวต
- **แก้ตัว:** คนละ 30 วินาที
- **โหวต:** เลือกผู้ถูกเสนอชื่อ 1 คน หรือ "งดออกเสียง" · ค่าเริ่มต้น: เปิดเผยว่าใครโหวตใคร (ตั้งค่า: โหวตลับ)
