# คู่มือผู้ใช้ — แววูฟ (เกมหมาป่าออนไลน์ในเว็บ Winter Community)

## 1) สำหรับผู้เล่น

1. ล็อกอินที่หน้าแรกด้วย **ชื่อ + รหัสผ่าน** (ชื่อใหม่ = ตั้งรหัสผ่านของชื่อนั้น · ชื่อเดิม = กรอกรหัสเดิม)
   - ติ๊ก "บันทึกรหัสผ่านไว้ในเครื่องนี้" = เปิดหน้าล็อกอินมาแล้วชื่อ/รหัสถูกกรอกให้
   - ติ๊ก "จำการเข้าสู่ระบบ" = ไม่ต้องล็อกอินใหม่ทุกครั้ง (ไม่ติ๊ก = ปิดเบราว์เซอร์แล้วต้องล็อกอินใหม่)
   - **เหรียญ ของที่ซื้อ และอวตารตามบัญชีไปทุกเครื่อง** (ล็อกอินชื่อเดิมที่เครื่องไหนก็ได้ของเดิม)
2. กด **เล่นเกมแววูฟ** → สร้างห้อง (ได้รหัส 5 ตัว) หรือกรอกรหัสห้องของเพื่อน
3. เจ้าของห้องตั้งค่า/เลือกชุดบท แล้วกด **เริ่มเกม** · ทุกคนกด "พร้อมแล้ว" หลังดูบทของตัวเอง
4. ปุ่ม **วิธีเล่น** (หน้าเมนูและในล็อบบี้) มีสรุปกติกา ลำดับเฟส และรายละเอียดทุกบท · ปุ่ม **ลำโพง** ที่หัวห้องเปิด/ปิดเสียง

### ลำดับเกม
- **กลางคืน (เฟสเดียว):** ทุกบทที่มีความสามารถเลือกเป้าหมาย **พร้อมกัน** แล้วระบบคำนวณผลทั้งหมดตอนจบคืน · คนที่ไม่มีอะไรทำเห็นหน้าจอ "หลับตา" เหมือนกัน
- **เช้า → อภิปราย → เสนอชื่อ → แก้ตัว → โหวต → ประหาร** แล้ววนกลับกลางคืน
- ถ้าคุณตาย หรือถูกเปลี่ยนฝ่าย (แวมไพร์กัด ลัทธิชวน หมาป่าอัลฟ่า ฯลฯ) จะมีกล่องแจ้งเตือน **เฉพาะคุณ** บอกสาเหตุ/บทที่ทำ — คนอื่นไม่เห็น
- แชทลับของพวกเดียวกัน (หมาป่า/แวมไพร์/ลัทธิ/คู่รัก) พิมพ์ได้เฉพาะ **กลางคืน** กลางวันคุยลับไม่ได้ (ผู้ตายคุยกันได้ตลอด)

## 2) สำหรับเจ้าของเว็บ (ตั้งค่าครั้งเดียว)

### ร้านค้า · กาชา · โค้ดเซ็ตพิเศษ (เพิ่มใหม่)
**รัน `supabase_gacha_migration.sql` ใน Supabase SQL Editor ก่อน deploy** (ไฟล์เดียว รันซ้ำได้ปลอดภัย) — ไม่งั้นหมุนกาชา/แลกโค้ดไม่ได้
- ของแต่งตัวมี (รวมทรงผม/ตา/ปากใหม่ 91 แบบ) ~7,100 ชิ้น: ของเดิม + เสื้อลาย 80 + **คอลเลกชันแรปเปอร์ 🎤** + **13 คอลเลกชันธีม** (ซามูไร/ไซเบอร์พังก์/ฮาโลวีน/อวกาศ/โจรสลัด/ขนมหวาน/ฟาโรห์/พิกเซล/ไทยประยุกต์/คริสต์มาส/พ่อมด/ซุปเปอร์ฮีโร่/คาวบอย ชุดละ 10 ชิ้น) + **โทนสี 12 แบบ** ของทุกชิ้น (หมวก/เสื้อ/แว่น/ของประดับ/เอฟเฟกต์/ฉาก/หลุมศพ) · ร้านมีค้นหา/กรองระดับ/โทนสี/คอลเลกชัน/เรียงราคา
- **กาชา 3 วงล้อ** (เงิน 60 · ทอง 180 · เพชร 500 เหรียญ ต่อครั้ง หมุน ×10 ได้) อัตราต่างกัน วงล้อเพชรไม่มีของธรรมดา · ของซ้ำคืนเหรียญ 40% ของราคา · เซิร์ฟเวอร์สุ่มและหักเหรียญเอง (atomic)
- **เซ็ตพิเศษ 4 เซ็ต** (WINTER · Nongfloat ชมพู · Mos · KhowFang สายรุ้ง) เซ็ตละ 7 ชิ้น มีชื่อเจ้าของอยู่บนของทุกชิ้น — ไม่ขายในร้าน ไม่ออกกาชา ได้จาก **โค้ดแลก** เท่านั้น (เก็บเฉพาะแฮชของโค้ดในโค้ดโปรแกรม ไม่ระบุโค้ดในเอกสารนี้) · โค้ดแลกซ้ำในกระเป๋าเดียวกันไม่ได้ · เดาโค้ดได้ไม่เกิน 10 ครั้ง/นาที

### อัปเกรดจากเวอร์ชันก่อน (ระบบบัญชีฝั่งเซิร์ฟเวอร์ + rate limit)
**รัน `supabase_auth_migration.sql` ใน Supabase SQL Editor ก่อน แล้วค่อย deploy โค้ดใหม่** — ไฟล์นี้ไฟล์เดียวพอ (รันซ้ำได้ปลอดภัย) ทำให้: รหัสผ่านถูกย้ายไปตารางลับ `winter_credentials` ที่เบราว์เซอร์อ่านไม่ได้เลย · ลบคอลัมน์รหัสผ่านเดิมออกจากตารางสาธารณะ · เพิ่มตัวจำกัดความถี่ · รหัสเดิมของทุกคนยังใช้ได้ (อัปเกรดเป็น scrypt ตอนล็อกอินครั้งถัดไป)

### Supabase (ตั้งโปรเจกต์ใหม่ทั้งหมด — SQL Editor รันทีละไฟล์ รันซ้ำได้ปลอดภัย)
1. `supabase_setup.sql` — ตารางหลักของเว็บ (ผู้ใช้/คะแนน/แชท/เพื่อน) รวมคอลัมน์รหัสผ่านและ `mouse_avatar`
2. `supabase_cheese_game_setup.sql` — เกมหนูชีส
3. `supabase_werewolf_setup.sql` — เกมแววูฟ (ตาราง `ww_*` + กระเป๋าเงินผูกบัญชี)

เปลี่ยนโปรเจกต์ Supabase ใหม่ = ต้องรันครบทั้ง 3 ไฟล์

### Netlify → Site settings → Environment variables
| ชื่อ | ค่า | หมายเหตุ |
|---|---|---|
| `VITE_SUPABASE_URL` | Project URL | ใช้ฝั่งเว็บ |
| `VITE_SUPABASE_ANON_KEY` | anon key | ใช้ฝั่งเว็บ |
| `SUPABASE_URL` | Project URL (ค่าเดียวกัน) | **ฝั่งเซิร์ฟเวอร์ของเกมแววูฟ — ขาดตัวนี้เกมจะใช้หน่วยความจำชั่วคราวแล้วข้อมูลหาย** |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key | **ความลับ — ติ๊ก "Contains secret values" · ห้ามขึ้นต้น `VITE_`** |
| `WW_SECRET` (ไม่บังคับ) | ข้อความสุ่มยาวๆ | ความลับสำหรับสร้างตั๋วกระเป๋าของบัญชี · ไม่ตั้ง = ใช้ `SUPABASE_SERVICE_ROLE_KEY` แทน (เปลี่ยนค่านี้ = ตั๋วกระเป๋าทุกเครื่องหมดอายุ ต้องล็อกอินใหม่) |

ตั้งหรือแก้แล้วต้อง **Trigger deploy ใหม่** ถึงจะมีผล

### ตรวจว่าเกมต่อ Supabase จริง
ยิง `POST /.netlify/functions/ww-wallet-create` สองครั้ง ถ้าได้ `walletId` ซ้ำกัน/ตารางใน Supabase มีแถวเพิ่ม = ต่อจริง · ถ้าได้ค่าใหม่ทุกครั้งและตาราง `ww_wallets` ว่าง = ยังใช้หน่วยความจำ (เช็ก env ตามตารางด้านบน)

### ข้อควรรู้
- ชื่อบัญชีเก่าที่ยังไม่เคยตั้งรหัส: **ใครล็อกอินก่อนได้ตั้งรหัสและครอบครองชื่อนั้น** — เจ้าของชื่อควรล็อกอินเป็นคนแรก
- **รหัสผ่านตรวจที่เซิร์ฟเวอร์ทั้งหมด**: เก็บแบบ scrypt ในตาราง `winter_credentials` (เบราว์เซอร์อ่านไม่ได้) · ล็อกอินสำเร็จได้ session token อายุ 60 วัน (เก็บในเครื่องตาม "จำการเข้าสู่ระบบ") · เดารหัสเกิน 8 ครั้ง/นาทีต่อชื่อ = ถูกบล็อกชั่วคราว
- **ตัวจำกัดความถี่ (rate limit)** ทุกเส้นทางของเกม (เช่น สร้างห้อง 10/นาที ต่อ IP) เกินแล้วตอบ 429 · ถ้าฐานข้อมูลตัวนับมีปัญหา จะปล่อยผ่านเพื่อไม่ให้เกมเล่นไม่ได้
- ลบผู้ใช้จากหน้าแอดมิน จะไม่ลบรหัสผ่านที่ตั้งไว้ (ตารางลับ) — ถ้าต้องล้างชื่อใดให้ลบแถวใน `winter_credentials` ที่ Supabase
- ปรับค่าเริ่มต้นของกติกา (เช่น ฝูงหมาป่าเลือกไม่ตรงกัน = สุ่ม) ได้ที่หน้าตั้งค่าห้องของเจ้าของห้อง

## 3) ตรวจสุขภาพโค้ดก่อนปล่อย
```bash
npm test          # เทสต์ทั้งหมด (กติกา · เซิร์ฟเวอร์ · ลองโกง · ความไม่ขึ้นกับลำดับกด)
npm run sim       # จำลองเกมบอท 500+ เกม ต้องจบทุกเกม ไม่มีแอคชันถูกปฏิเสธ
npm run build     # ต้องผ่าน
```

## Winter Community + ระบบเลเวล (อัปเดตล่าสุด)
- **หน้าแรกของเว็บ = Winter Community:** แนะนำเกม (แววูฟ/หนูชีส/คลังข้อสอบ) · ผู้คน (เพื่อน/ค้นหา/คำขอ/ออนไลน์) · แชท (ห้องรวม + ส่วนตัวกับเพื่อน) · อันดับ (แววูฟ/ข้อสอบ) — เมนูซ้ายบนเดสก์ท็อป แถบล่างบนมือถือ
- **เลเวล/XP ในแววูฟ:** เล่นจบได้ XP (เล่น +30 · ชนะ +40 · รอด +15) · ขึ้นเลเวลได้เหรียญโบนัส (เลเวล × 30) · ดูสถิติ/อันดับ/เพื่อนที่ปุ่ม "โปรไฟล์" หน้าแรกของเกม (ต้องล็อกอินบัญชี)
- **รายงานผู้เล่น:** ไอคอนธงข้างข้อความแชทในเกม → เลือกเหตุผล → ผู้ดูแลเห็นในหน้า Admin (ต้องตั้ง `WW_ADMINS` และล็อกอินด้วยบัญชีแอดมิน)
- ต้องรัน `supabase_community_migration.sql` ใน Supabase ก่อน (ตาราง ww_progress, ww_reports)

## ร้านค้าใหม่ + คอลเลกชันวาเลนไทน์ 💘
- **หน้าร้านค้า (แท็บ 🛍️):** คอลเลกชันเด่น · "ใกล้ครบแล้ว" · คอลเลกชันทั้งหมด 14 ชุด (ตัวอย่างใส่ชุดบนหน้าตา/ผมของคุณเอง) · ทางลัดกาชา/แลกโค้ด
- **หน้าคอลเลกชัน:** ลองใส่ทั้งชุด · ดูทีละชิ้น · ซื้อทีละชิ้น หรือ **ซื้อทั้งชุดลด 20%** (คิดเฉพาะชิ้นที่ยังไม่มี) · ใส่ทั้งชุดเมื่อสะสมครบ
- **วาเลนไทน์ 💘:** กุหลาบแดง หัวใจ ปีกคิวปิด และค่ำคืนใต้ดวงจันทร์หัวใจ ชุดละ 10 ชิ้น ออกจากกาชาได้ด้วย

## บอท 🤖 (ไว้ทดสอบ / เติมคนให้ครบ)
- เจ้าของห้องกด **+1 / +3 / +5 / ครบ 8 คน** ในกล่อง "🤖 บอท" ใต้รายชื่อผู้เล่นในล็อบบี้ · **ลบบอททั้งหมด** ได้ในที่เดียวกัน
- บอทเล่นเองอัตโนมัติ (ใช้ความสามารถตอนกลางคืน เสนอชื่อ โหวต ยิง) และสุ่มโหวตข้ามช่วงอภิปรายเพื่อไม่ให้เกมค้าง
- บอททำงานตอนมีผู้เล่นที่เป็นคนเปิดห้องอยู่ (ทุก ~3 วินาที) · บอทไม่ได้เหรียญ/XP/อันดับ

## หน้าเล่นแบบใหม่: บอกชัดว่าต้องทำอะไร
- **แผงสถานะบนสุด** ตอบ 4 อย่างเสมอ: ตอนนี้อยู่ช่วงไหน (แถบขั้นตอน 🌙☀️💬🗳️🛡️⚖️🔨 ไฮไลต์ช่วงปัจจุบัน) · ถึงตาคุณไหม/ต้องกดอะไร (การ์ดสีเหลือง = ถึงตาคุณ, เขียว = รอคนอื่น, แดง = สำคัญ/อันตราย) · รออะไรอยู่ (แถบ เสนอชื่อแล้ว 3/7) · เมื่อกี้เกิดอะไรขึ้น (เหตุการณ์ล่าสุด)
- ปุ่ม **"ช่วงนี้คืออะไร"** อธิบายช่วงปัจจุบันสั้นๆ · แตะ **"บทของคุณ"** ดูความสามารถ · เวลาถอยหลังเป็นวงกลม (แดงเมื่อเหลือ 10 วิ)
- **📜 เหตุการณ์** (ปุ่มในแผงสถานะ): ประวัติทั้งเกมแยกตามวัน · แท็บ **🌐 สาธารณะ** = ทุกคนเห็นเหมือนกัน (ใครตาย ผลโหวต เสนอชื่อ) · แท็บ **🎭 ของฉัน** = เห็นแค่คุณ (ผลส่อง คู่รัก ถูกเปลี่ยนฝ่าย ฯลฯ)
- **หน้าเล่นไม่ต้องเลื่อนเยอะ:** ปุ่มลงมือ (ยืนยัน/โหวต/ยิง/ข้ามอภิปราย) ติดขอบล่างเสมอ · แชทเป็นปุ่ม "แชท" ลอยมุมขวาล่าง (มีเลขข้อความใหม่) เปิดเป็นลิ้นชัก · ตารางผู้เล่นปรับจำนวนคอลัมน์ตามจำนวนคนให้เห็นทุกคนในหน้าเดียว · ผลส่วนตัวล่าสุดขึ้นเป็นแถบสั้นๆ ใต้แผงสถานะ
- **หน้าเล่นแบบแท็บล่าง 3 อัน:** 🎮 เกม (การ์ดบอกว่าต้องทำอะไร + ตารางผู้เล่น + ปุ่มลงมือติดล่าง) · 💬 แชท (เต็มหน้า) · 📜 เหตุการณ์ (สาธารณะ/ของฉัน) — แท็บละหน้าเต็มจอ ไม่ต้องเลื่อนหา · ถึงตาคุณ ระบบพากลับแท็บเกมให้เอง และมีป้าย "ถึงตาคุณ!" บนแท็บเกมถ้าคุณอยู่แท็บอื่น · แตะ ? ในการ์ดเพื่อดูว่าช่วงนี้คืออะไร
- **เห็นตัวละครชัดๆ:** การ์ดสถานะมีตัวละครของคุณขนาดใหญ่ (แตะเพื่อดูเต็มจอ) · ตารางผู้เล่นใช้การ์ดใหญ่ 3 คอลัมน์เมื่อมีไม่เกิน 9 คน · แตะการ์ดของใครก็ได้ (หรือไอคอนแว่นขยายตอนกำลังเลือกเป้าหมาย) เพื่อดูชุดแต่งตัวเต็มจอ
- **ผู้เล่นกี่คนก็พอดีจอ:** ตารางผู้เล่นคำนวณจำนวนคอลัมน์จากพื้นที่ว่างจริง (หักแถบแท็บและปุ่มลงมือ) ให้ทุกคนอยู่ในจอเดียว — 8 คนได้การ์ดใหญ่ 3 คอลัมน์ 30 คนใช้ 6 คอลัมน์ · แถบปุ่มลงมือตัดข้อความซ้ำออกให้เตี้ยลง (คำอธิบายอยู่ที่การ์ดสถานะ) · การ์ดสถานะเล็กลง และมีปุ่ม "👗 ดูตัวฉัน" ไว้อวดตัวละคร
