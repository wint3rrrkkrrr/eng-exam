## 1. ภาพรวมหนึ่งหน้า

ผู้เล่นทุกคนได้รับ **บทบาทลับ** แบ่งเป็นฝ่าย:

| ฝ่าย | เป้าหมาย |
|---|---|
| 🏡 **ชาวบ้าน** (village) | กำจัดหมาป่าให้หมด |
| 🐺 **หมาป่า** (werewolf) | ฆ่าชาวบ้านจนหมาป่ามีจำนวนเท่าหรือมากกว่าฝ่ายอื่น |
| 💘 **คู่รัก** (lovers) | ถ้าเป็นคู่รักข้ามฝ่าย: ต้องรอดเหลือสองคนนั้นเท่านั้น |
| 🎭 **ฝ่ายที่สาม** (solo) | มีเงื่อนไขชนะของตัวเอง (คนบ้า, ฆาตกรต่อเนื่อง) |

เกมเดินเป็นรอบ: **กลางคืน (ใช้พลังลับ) → เช้า (ประกาศคนตาย) → กลางวัน (อภิปราย) → โหวตประหาร** วนไปจนมีฝ่ายชนะ

## 2. พรีเซ็ตกติกา

เลือกได้ในหน้าตั้งค่า ปุ่ม **"ค่ามาตรฐาน"** = คืนค่าพรีเซ็ตที่เลือกไว้

| พรีเซ็ต | เนื้อหา |
|---|---|
| **มาตรฐาน (Millers Hollow)** ⭐ ค่าเริ่มต้น | ชาวบ้าน · หมาป่า · ผู้หยั่งรู้ · แม่มด · นายพราน · กามเทพ · เด็กหญิงตัวน้อย · หัวหน้าหมู่บ้าน · ผู้พิทักษ์ |
| **เริ่มต้นง่าย (มือใหม่)** | ชาวบ้าน · หมาป่า · ผู้หยั่งรู้ · หมอ — ปิดระบบคู่รัก/หัวหน้าหมู่บ้าน เพื่อให้เรียนง่าย |
| **Ultimate Werewolf** | เพิ่มเมสัน · ลูกหมาป่า · ผู้ถูกสาป · คนโง่ · สมุนหมาป่า · ใช้คะแนนสมดุลแบบ UW |
| **กำหนดเอง** | เจ้าของห้องติ๊กบททีละตัวและกำหนดจำนวน |

🔀 **จุดต่างที่ทำเป็นตัวเลือก (MH vs UW)**

| หัวข้อ | MH (ค่าเริ่มต้น) | UW |
|---|---|---|
| ผู้หยั่งรู้เห็นอะไร | เห็น **บทจริง** | เห็นแค่ **ฝ่าย** (หมาป่า/ไม่ใช่หมาป่า) |
| เสียงเสมอตอนโหวต | **ไม่มีใครตาย** | **โหวตใหม่** ระหว่างคนที่คะแนนเท่ากัน |
| เปิดบทคนตาย | เปิด **บทเต็ม** | ตั้งค่าได้ มักเปิดแค่ **ฝ่าย** |
| คืนแรกฆ่าได้ไหม | **ฆ่าได้** | ตั้งค่าได้ บางฉบับ "คืนแรกไม่มีใครตาย" |
| ผู้พิทักษ์กันคนเดิมซ้ำ | **ห้ามซ้ำสองคืนติด** | ตั้งค่าได้ |
| หัวหน้าหมู่บ้านเสียงเสมอ | หัวหน้า **ตัดสินชี้ขาด** | หัวหน้าโหวต **นับ 2 เสียง** |

## 3. ลำดับเฟสของเกม

```
LOBBY            เข้าห้อง ตั้งค่า เลือกบท ตรวจจำนวนบท = จำนวนผู้เล่น
   ↓ (เจ้าของห้องกดเริ่ม → แจกบทลับ)
ROLE_REVEAL      ทุกคนเปิดดูบทของตัวเอง แล้วกด "พร้อม"
   ↓ (รอทุกคนพร้อม)
NIGHT            ผู้ดำเนินเกมเรียกทีละบทตามลำดับข้อ 4
   ↓
DAWN_RESOLVE     เซิร์ฟเวอร์คิดผลตามลำดับข้อ 5  ← ไม่มี UI ให้กด
   ↓
MORNING          ประกาศผู้เสียชีวิต + เหตุการณ์ต่อเนื่อง (นายพราน/คู่รัก/ส่งต่อตำแหน่ง)
   ↓ ★ ตรวจเงื่อนไขชนะทุกครั้งที่มีคนตาย
ELECTION         เลือกตั้งหัวหน้าหมู่บ้าน (เฉพาะหลังคืนแรก ถ้าเปิดใช้)
   ↓
DISCUSSION       อภิปราย + ตัวจับเวลา (ปิดแชทได้ถ้าคุยกันจริง)
   ↓
VOTE             โหวตประหาร
   ↓
EXECUTION        ประกาศผล + ผลพลอยได้ (คนโง่รอด, นายพรานยิง, ส่งต่อตำแหน่ง)
   ↓ ★ ตรวจเงื่อนไขชนะ
   └→ กลับไป NIGHT (วันถัดไป)   หรือ   → GAME_OVER
```

**★ กฎสำคัญ:** ตรวจเงื่อนไขชนะ **ทุกครั้งที่มีคนตาย** ไม่ใช่เฉพาะท้ายรอบ
(เช่น นายพรานยิงหมาป่าตัวสุดท้ายตาย → ชาวบ้านชนะทันที ไม่ต้องรอโหวตวันถัดไป)

### หน้าจอจบเกม
- เปิดบทของ **ทุกคน** (รวมคนที่รอด)
- **ไทม์ไลน์เหตุการณ์ทั้งเกม** จาก `ww_events` (คืนที่ 1 ใครกัดใคร ใครกันใคร ใครโหวตใคร)
- ปุ่ม "เล่นอีกครั้ง" (กลับล็อบบี้ คงค่าตั้งค่าเดิม)

### 4.1 กันการเดาจากเวลา (anti-timing-tell) — ข้อบังคับ

ถ้าเกมข้ามบทที่ไม่มี/บทที่ตายไปแล้วแบบทันที ผู้เล่นจะจับทางได้ว่า "คืนนี้เร็วผิดปกติ = ผู้หยั่งรู้ตายแล้ว"

**กฎ:** ทุกช่องตื่น (รวมช่องที่ไม่มีคนเล่น/คนตายแล้ว) ต้องกินเวลา **สุ่มในช่วงเดียวกัน**
- ค่าเริ่มต้น: **4–7 วินาที** ต่อช่อง
- ช่องที่มีคนเล่นจริง: อย่างน้อย `night_action_seconds` (ค่าเริ่มต้น 25 วินาที) แต่ถ้าคนนั้นกดเร็ว ก็ยังต้องรออย่างน้อยเวลาสุ่มขั้นต่ำก่อนไปช่องถัดไป
- ข้อความบรรยายต้องเหมือนกันทุกครั้ง: "ผู้หยั่งรู้ตื่นขึ้น…" ต้องขึ้นแม้ผู้หยั่งรู้จะตายแล้ว

## 5. ลำดับการตัดสินผลตอนเช้า (สำคัญที่สุด)

เซิร์ฟเวอร์คิดผลตามลำดับนี้ **เป๊ะๆ** และต้องมีเทสต์คุมทุกขั้น

```
ขั้น 1  รวบรวมความตั้งใจจะฆ่าทั้งหมดของคืนนี้
        ├─ การกัดของหมาป่า        (wolf_bite)
        ├─ เหยื่อรายที่สองของหมาป่าตัวใหญ่ (big_bad_wolf)
        └─ ฆาตกรต่อเนื่อง          (serial_kill)

ขั้น 2  การป้องกัน (ผู้พิทักษ์/หมอ)
        → ลบเฉพาะ "การกัดของหมาป่า" ออก  (ค่าเริ่มต้น: กันพิษแม่มดไม่ได้, กันฆาตกรต่อเนื่องไม่ได้ — ตั้งค่าได้)

ขั้น 3  ยาชุบชีวิตของแม่มด
        → ลบคนที่แม่มดเลือกชุบออกจากรายชื่อคนตาย
        ★ ถ้าหมอกันคนเดียวกันไว้แล้ว: แม่มดได้ยาคืน (ไม่เสียเปล่า) — ตั้งค่าได้: คืนให้ / เสียไปเลย
          (ค่าเริ่มต้น = คืนให้ เพราะยามีขวดเดียวทั้งเกม)

ขั้น 4  ยาพิษของแม่มด
        → เพิ่มคนที่ถูกวางยาเข้ารายชื่อคนตาย (หมอกันไม่ได้ ชุบไม่ได้)

ขั้น 5  ยืนยันรายชื่อคนตายรอบนี้ → บันทึกลง ww_events

ขั้น 6  คู่รักตายตาม (ลูกโซ่)
        → ถ้าคนในคู่รักตาย อีกคนตายด้วยทันที
        → วนซ้ำจนไม่มีคนตายเพิ่ม (รองรับกรณีมีหลายคู่)

ขั้น 7  นายพรานยิง (ลูกโซ่)
        → นายพรานทุกคนที่ตายในขั้น 1-6 ต้องยิงหนึ่งคน
        → ถ้ายิงไปโดนนายพรานอีกคน/คู่รัก → กลับไปขั้น 6 แล้ววนต่อ
        → วนจนไม่มีใครตายเพิ่ม (มีลิมิตกันวนไม่จบ)

ขั้น 7b เงื่อนไขของบทอื่นที่ทำงานตอนตาย (ตั้งค่าได้ว่ารวมในลูกโซ่ไหม)

ขั้น 8  ส่งต่อตำแหน่งหัวหน้าหมู่บ้าน
        → ถ้าหัวหน้าหมู่บ้านตาย ต้องเลือกผู้สืบทอดก่อนเกมเดินต่อ

ขั้น 9  ตรวจเงื่อนไขชนะ (ข้อ 7)
```

### 5.1 ตัวอย่างที่ต้องได้ผลตรงนี้ (เป็นเคสเทสต์)

| สถานการณ์ | ผลที่ถูก |
|---|---|
| หมาป่ากัด A + หมอกัน A | A **รอด** |
| หมาป่ากัด A + หมอกัน A + แม่มดชุบ A | A รอด และแม่มด **ได้ยาชุบคืน** (ค่าเริ่มต้น) |
| หมาป่ากัด A + แม่มดวางยา A | A **ตาย** (ตายครั้งเดียว ไม่นับสองรอบ) |
| หมอกัน A + แม่มดวางยา A | A **ตาย** (หมอกันพิษไม่ได้) |
| หมาป่ากัด A, A เป็นคู่รักกับ B | **ตายทั้งคู่** |
| หมาป่ากัด A (คู่รักกับ B) + แม่มดวางยา B | ตาย A,B — ไม่ลูปซ้ำ |
| นายพรานถูกวางยาตาย | ยิงได้ (ค่าเริ่มต้น "รวมกรณีถูกพิษ" = เปิด) |
| นายพรานตายตามคู่รัก | ยิงได้ (ตั้งค่าได้ ค่าเริ่มต้น = เปิด) |
| นายพรานยิงหัวหน้าหมู่บ้าน | หัวหน้าตาย → **ต้องส่งต่อตำแหน่ง** |
| หมาป่าเห็นไม่ตรงกัน | ตามค่าตั้งค่า (ค่าเริ่มต้น: **ไม่มีใครตาย**) |

## 6. กติกาการโหวต

| หัวข้อ | ตัวเลือก | ค่าเริ่มต้น |
|---|---|---|
| ความลับ | โหวตลับ / เปิดเผยว่าใครโหวตใคร | **เปิดเผย** (MH) |
| ข้ามโหวต | ได้ / ไม่ได้ | **ได้** |
| เกณฑ์ชนะ | คะแนนสูงสุดพอ / ต้องเกินครึ่งของคนที่รอด | **สูงสุดพอ** |
| เสียงเสมอ | ① ไม่มีใครตาย ② โหวตใหม่ระหว่างคนที่เท่ากัน แล้วถ้ายังเสมอ = ไม่มีใครตาย ③ สุ่ม ④ หัวหน้าหมู่บ้านตัดสิน | **④ ถ้ามีหัวหน้า ไม่มีหัวหน้า → ①** |
| คะแนนหัวหน้าหมู่บ้าน | นับ 2 เสียง / ตัดสินชี้ขาดตอนเสมอ | **ตัดสินชี้ขาด** (MH) 🔀 |
| คนตายโหวตได้ไหม | ไม่ได้ | **ไม่ได้** (ตายคือจบ) |
| หมดเวลาแล้วยังไม่โหวต | นับเป็นข้าม / สุ่มเป้า | **นับเป็นข้าม** |
| คนโง่ | ถูกโหวตแล้วรอด แต่เสียสิทธิ์โหวตตลอดเกม | — |

## 7. เงื่อนไขชนะ + ลำดับความสำคัญ

### 7.1 เงื่อนไขของแต่ละฝ่าย

| ฝ่าย | ชนะเมื่อ | ตั้งค่า |
|---|---|---|
| 🏡 ชาวบ้าน | **หมาป่าทุกตัวตาย** | — |
| 🐺 หมาป่า | หมาป่าที่รอด **≥** ผู้เล่นฝ่ายอื่นที่รอด | เกณฑ์ปรับได้: `>=` (ค่าเริ่มต้น) หรือ `>` หรือ "ฝ่ายอื่นตายหมด" |
| 💘 คู่รักข้ามฝ่าย | เหลือรอด **สองคนนั้นเท่านั้น** | เปิด/ปิดได้ (ค่าเริ่มต้น: **เปิด**) |
| 🤪 คนบ้า | **ถูกโหวตประหาร** | — |
| 🔪 ฆาตกรต่อเนื่อง | เหลือรอดคนเดียว (หรือเหลือ ≤ เกณฑ์ที่ตั้ง) | — |

### 7.2 ลำดับความสำคัญเมื่อหลายฝ่ายชนะพร้อมกัน

เมื่อเหตุการณ์เดียวทำให้หลายฝ่ายเข้าเงื่อนไขชนะพร้อมกัน ให้ตัดสินตามลำดับนี้ (บนสุดชนะ):

```
1. คู่รักข้ามฝ่าย  (เงื่อนไขเฉพาะที่สุด: ต้องเหลือ 2 คนนั้นพอดี)
2. ฝ่ายที่สามรายบุคคล  (คนบ้าถูกประหาร / ฆาตกรต่อเนื่องเหลือคนเดียว)
3. หมาป่า
4. ชาวบ้าน
```

**เหตุผล:** เงื่อนไขที่แคบกว่าควรชนะเงื่อนไขที่กว้างกว่า เช่น เหลือหมาป่า 1 + ชาวบ้าน 1 ที่เป็นคู่รักกัน → ทั้ง "หมาป่า ≥ ฝ่ายอื่น" และ "คู่รักเหลือสองคน" เป็นจริง → **คู่รักชนะ**

⚠️ นี่เป็นการตัดสินใจเชิงออกแบบ ไม่ใช่กติกาที่ MH/UW ระบุชัด → ดู `OPEN_QUESTIONS.md` Q9
🤪 กรณีคนบ้าถูกประหาร: ค่าเริ่มต้น = **คนบ้าชนะและเกมจบทันที** (ตั้งค่าได้: ให้เกมเดินต่อแล้วคนบ้าแค่ "ได้แต้มชนะส่วนตัว")

## 11. ตัวช่วยสมดุล (Role Balance)

หน้าตั้งค่าต้องแสดง **ตัวบอกความสมดุล** แบบ Ultimate Werewolf:
แต่ละบทมี "คะแนน" (บวก = ช่วยชาวบ้าน, ลบ = ช่วยหมาป่า) แล้วรวมคะแนนทั้งเกมเทียบกับช่วงที่ควรเป็น

### 11.1 สัดส่วนหมาป่าที่แนะนำ

| ผู้เล่น | หมาป่า | หมายเหตุ |
|---|---|---|
| 5–6 | 1 | เกมสั้น ควรปิดบทพิเศษเยอะๆ |
| 7–8 | 2 | |
| 9–11 | 2 | |
| 12–15 | 3 | |
| 16–20 | 4 | |
| 21–25 | 5 | |
| 26–30 | 6 | เกมยาว ควรเพิ่มบทชาวบ้านมีพลัง |

สูตรคร่าวๆ: `หมาป่า ≈ ปัดเศษ(จำนวนผู้เล่น ÷ 4)` และ **หมาป่าต้องน้อยกว่าครึ่งเสมอ**

### 11.2 คะแนนบท (ค่าเริ่มต้น ปรับได้ในไฟล์ข้อมูลบทบาท)

| บท | คะแนน |
|---|---|
| ชาวบ้าน | +1 |
| ผู้หยั่งรู้ | +6 |
| แม่มด | +5 |
| ผู้พิทักษ์/หมอ | +4 |
| นายพราน | +3 |
| เมสัน (ต่อคน) | +3 |
| เด็กหญิงตัวน้อย | +2 |
| หัวหน้าหมู่บ้าน (ตำแหน่ง) | +1 |
| กามเทพ | 0 *(กลางๆ เพราะเปลี่ยนเกมได้ทั้งสองทาง)* |
| คนโง่ | 0 |
| คนบ้า | 0 *(ฝ่ายที่สาม)* |
| หมาป่า | −6 |
| ลูกหมาป่า | −8 |
| หมาป่าตัวใหญ่ | −9 |
| หัวหน้าฝูง | −7 |
| สมุนหมาป่า | −2 |
| เด็กป่า | −3 |
| ผู้ถูกสาป | −2 |
| ขโมย | 0 |
| ฆาตกรต่อเนื่อง | −4 *(ฝ่ายที่สาม)* |

**เกณฑ์อ่านผล:** รวมคะแนนทุกบทในเกม → ควรอยู่ในช่วง **−2 ถึง +4** ถ้าออกนอกช่วงให้แสดงคำเตือนภาษาไทย เช่น
- รวม < −2 → "⚠️ หมาป่าเปรียบได้มาก ลองเพิ่มผู้หยั่งรู้หรือหมอ"
- รวม > +4 → "⚠️ ชาวบ้านเปรียบได้มาก ลองเพิ่มหมาป่าหรือลดบทพิเศษ"

> ⚠️ คะแนนชุดนี้เป็นค่าเริ่มต้นที่ตั้งขึ้นให้ใช้งานได้ ไม่ใช่ตัวเลขทางการจากหนังสือ UW → `OPEN_QUESTIONS.md` Q11
